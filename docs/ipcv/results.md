## Dataset

- Image size 640x480, tables: wood / slate / laminate, plates: white / off-white / grey.
- 0-4 portions per plate (dal, gravy, palak, chapati, biryani colours), ~45 % of multi-portion plates have a touching pair.
- Uneven lighting (gradient 10-30 % + vignette), Gaussian noise sigma 3-8, salt-and-pepper 0.1-0.5 %.
- Development set (thresholds tuned here): seeds 2026-2085 (60 images).
- Held-out test set: seeds 5000-5119 (120 images).

## Endpoint

`POST /api/vision/recognize`, 20 requests (JPEG q90, 640x480, no outlet so no DB query): mean 61.1 ms, p50 61.7 ms, p95 66.5 ms. Through JPEG compression the fill-ratio MAE is 0.0008 and portion-count accuracy 100.0 %.

Large phone photos (JPEG q90, 4000x3000, 869 KB): p50 93.0 ms, p95 122.1 ms (decoded at reduced size via JPEG DCT scaling, then normalised to 512 px).

Robustness: the endpoint returns 200 with the same keys for a photo with no plate, an all-black frame, an 8x8 image, a 4000x3000 photo and a PNG with alpha; any exception inside the pipeline falls back to the original heuristic-v0 colour statistics (covered by tests).

## Ablation: DFT illumination flattening

Held-out set without the low-pass illumination correction: fill MAE 0.0014, count accuracy 100.0 % (with it: 0.0010, 99.2 %). The shading field is estimated only from neutral (low-chroma) plate pixels so food does not pull it down. The effect is small either way because the food cue already down-weights lightness, and the synthetic lighting (linear gradient + vignette) is milder than real kitchen shadows.

## Compression (Unit 6)

Run-length encoding of the full-resolution food mask (row-major runs, LEB128 varints): 415.7 bytes per mask on average. Aggregate compression ratio 59.11x vs a packed 1-bit bitmap and 472.91x vs an 8-bit mask (median per image 55.48x vs bitmap). The API also returns the RLE of the 128x128 normalised mask (`features.maskRle`).

## Limitations

- Synthetic data is cleaner than real photos (flat top-down view, round plates, food colours that differ from the plate).
- White food (rice, curd) on a white plate has almost no colour distance and would be under-segmented.
- Dish identity is not recognised from pixels: no labelled real dataset exists to train a classifier honestly. The endpoint ranks the outlet's own dishes by recent waste and prep volume, nudged by dominant colour.
- Strongly overlapping portions (neck wider than ~84 % of the smaller portion's radius) merge into one segment.
